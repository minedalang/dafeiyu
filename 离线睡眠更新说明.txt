小鲸鱼生命系统 · 关机离线睡眠补算补丁（基于用户上传的 dafeiyu-ai-windows-conda-test.zip）

【安装】
1. 退出桌宠和设置窗口，备份项目及现有的 whale-life-state.json。
2. 将本 ZIP 里的 pet 文件夹覆盖到包含 2-Run-Windows.bat 的项目根目录。
   README.md 是文档更新，可一同覆盖；tests 目录仅用于开发自测。
3. 运行 2-Run-Windows.bat，无需重装 Conda，也不用改 API Key。

【逻辑】
- Windows 电脑本地时间 22:00 至次日 07:00，离线时间自动按睡眠结算。
- 电脑白天关机时，不会默认整段算睡眠。
- 如果关机/异常退出前小鲸鱼正处于已成功执行的午睡，则最多补算该次
  计划的剩余午睡时间（不因为循环播放动画而重复计算）。
- 最多只补算关机前后最近 24 小时内的时间。离线多日只采用最后一天。
- 每次离线补算会立即保存新的结算时间，避免二次启动重复恢复。
- 生命状态面板「最近生活经历」会记录“离线睡眠 X 小时 Y 分钟”。
- 不会在关闭电脑期间执行任何程序或模型调用；只是重启时模拟生命状态。

【验收】
- 晚上例如 23 点关闭程序/关机，第二天早上 8 点启动：困意明显下降，
  精力明显恢复；生命经历出现离线睡眠记录。
- 白天关闭程序两小时再启动：不会出现夜间睡眠补算记录。
- 关闭程序后立即重启：不会获得额外夜间睡眠奖励。

【测试边界】
基于 Python 逻辑测试并非 Windows 实机测试。程序持续在后台运行但
电脑没有关机时，仍遵循已有的在线活动计划及困意更新规则，不等于
本次离线补算。系统时钟/时区被人为调整会影响依据当地时间的估算。
