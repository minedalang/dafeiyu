# AI 搭话、点击回应与人设（System Prompt）

> 对照：`pet/autonomy_speech.py`、`pet/autonomy.py`、`pet/app.py`、`pet/chat/ai_settings_page.py`、`pet/chat/prompt.py`（若版本路径不同，按实际代码为准）。

## 1. 同一人设，四种用途

| 通道 | 人设来源 | 额外规则 | 是否可能使用 API |
| --- | --- | --- | --- |
| AI 对话窗口 | 角色自带设定 + AI 设置中的 System Prompt | 正常对话/历史管理 | 是 |
| AI 自主决策的附带台词 | 同一有效角色人设 | 只返回合规动作计划、只能用已有素材 | 是 |
| 独立自主搭话 | 同一有效角色人设 | 此次可选择安静，只返回 `say` JSON | 是 |
| 用户点击后的回应 | 同一有效角色人设 | 根据点击和当前生命/活动状态决定是否回应 | 是 |

修改位置：**AI 设置 → 模型与连接 → 小鲸鱼性格 / 说话风格（System Prompt）**。角色身份仍由角色素材设定提供，用户自定义口吻补充并优先约束说话风格。**“人设统一”不等于四条链共用相同系统指令**：动作规划还必须遵守活动 JSON，搭话只允许说一句话或不说。

## 2. 独立主动搭话的定时机制

| 项目 | 当前规则 |
| --- | --- |
| 最短 / 最长 | 默认 **3～6 分钟**，在 AI 自主行为设置里分别调成 1～60 分钟 |
| 固定频率 | 两个数相同，例如 5～5 分钟；表示固定间隔**检查是否搭话**，非固定必须开口 |
| 计时检查 | 每 15 秒检查是否满足时间与场景条件，故实际触发会有偏差 |
| 允许的情境 | 自主行为已开启、**正在持续活动**、不是睡眠、无占用中的 AI 请求、气泡可显示等 |
| 睡眠 / 午睡 | 不触发自发搭话，不会为了说话把睡眠动画切掉 |
| 近期聊天 | 用户消息会推迟下一次自发搭话判断 |
| 冷却 | 最近实际说过话不足约 45 秒时跳过 |
| 失败 / AI 选安静 | 不显示气泡；**失败当前仍按一般随机间隔等待，不是 30 秒自动重试** |
| 有人主动点击 | 走独立点击回复路径，不需要等待上一轮 3～6 分钟结束 |

**示例：** 状态面板显示“约 321 秒后再判断”，意思是 5 分 21 秒后再次检查是否需要说话；不是 321 秒后一定会说。修改上下界并保存后会重新安排下一次判断。

自主搭话后台请求超时上限约 **25 秒**、输出预算 **180 tokens**。模型允许返回 `{ "say": "" }` 表示选择安静，非空句子压到 **90 字**以内。重复的近期台词会被去重，不会每次循环同一个工作动画就重复同一句话。

## 3. 点击与自主搭话的区别

- **没有持续活动时**：普通单击保持原来的点击动画、音效；自主模式下还可能安排一次 AI 点击回应。
- **有持续活动时**：单击只算触碰，不打断、不额外请求 AI；需满足 **0.55 秒内、距离不超过约 36 像素**的双击才能结束持续活动/叫醒。
- 点击回复的 API 调用有约 **12 秒**限频；这是防刷接口，**不影响双击是否被认作打断**。
- 点击回复与持续动画分离，只显示文本，不应该在说话时偷换睡眠/工作动画。
- 点击气泡可能显示“回复小鲸鱼”按钮；目前点击触发的回复入口通常保留约 **8.5 秒**，自发搭话为约 **14 秒**。
- **免打扰场景**：一般自发搭话受免打扰/全屏限制；用户直接点击可按实现允许回应，但若气泡被阻止或已有告警占位，仍可能不显示。

## 4. JSON 协议与反重复

```json
{"say": "今天做完这件事，再玩一会儿吧。"}
```

或者：

```json
{"say": ""}
```

其他键、不合法 JSON 或服务返回错误均不会被当作执行指令。说话从不代表可操作鼠标、键盘或文件。最近显示的自发台词只在内存中保留少量记录用于去重；需要对话上下文时，使用聊天会话管理的正常历史机制。

## 5. 常见误解

| 问题 | 正确解释 |
| --- | --- |
| “为什么 321 秒这么长？” | 默认随机 **180～360 秒**，是正常范围 |
| “设置 1～1 分钟是否每分钟都会说？” | 不保证；当前持续活动、气泡和 AI 选择安静等都能跳过 |
| “AI 搭话失败为什么还等几分钟？” | 现在的失败逻辑不会自动 30 秒重试，仍使用原调度时间 |
| “我改 System Prompt，工作动画为什么没变？” | 人设主要影响身份/说话风格，动作还受素材白名单、活动类型与本地状态制约 |
| “单击睡觉的小鲸鱼为何不答我？” | 持续睡眠受单击保护；**双击叫醒**才允许正常交互 |
