## AI 与本地程序的职责边界

```text
用户操作 / 本地时间 / 生命状态 / 可选授权识屏
                     │
                     ▼
           AutonomyService 自主调度
                     │  (需要时发送模型请求)
                     ▼
              模型返回受约束 JSON
                     │  (本地白名单校验)
                     ▼
       行为控制器选择已有 WebM 动画/气泡
                     │
                     ▼
     WhaleLife 按“真实执行 + 经过时间”更新生命值
                     │
                     └── 状态 JSON / 监控面板 / 离线结算日志
```

**注意：** 自主行为与主动搭话是不同调度器；正常决策间隔 40 秒不代表会在 40 秒后打断当前工作或睡眠。睡眠的在线活动时长（目前通常十几到几十分钟）与关机后 22:00～07:00 的离线补算，也属于两套规则。

## 文档维护原则

- **行为由源码和测试确定**：一切默认值、时间窗口、白名单和打断规则均注明代码位置。不要把“希望以后实现”的想法写成“已经实现”。
- **规则 + 示例 + 数据字段 + 验证方法**：改动生命系统时同步维护四类说明；特别是离线时间计算应展示关机/开机时间样例。
- **识屏属于独立授权**：说明发送给第三方 API 的数据种类，不记录密钥、截图内容或用户聊天原文到诊断文档。
- **历史报告不代表当前行为**：`PR-REPORT-AI-AUTONOMY-2026-10-20.md` 是早期开发记录；以本索引所链接的机制文档为准。
- **版本差异先核对文件**：用户覆盖旧补丁、更新上游、切换 Chat/非 Chat 包后，实际行为可能不同。若文档与运行版本不一致，优先看当前运行目录里的源码和配置。

相关项目启动说明仍保留在根目录 [`WINDOWS-AI-TEST.md`](../WINDOWS-AI-TEST.md)；根目录 [`AI-UPDATE-INSTRUCTIONS.md`](../AI-UPDATE-INSTRUCTIONS.md) 说明早期补丁操作背景，具体最新机制以上述文档为准。
