# AI 自主桌宠（Mochi 风格的自主动作）

本工作区版本在原版大肥鱼的 WebM 动画 / 行走 / 交互系统外，加了一层独立的 LLM 决策器。
**没有重画形象，也不是通过模型实时生成动画**：模型只选择动作，原有 PySide6
动画控制器负责播放、碰撞、边界、点击、拖拽和抛掷。

下载的 `dafeiyu-mochi-ai-autonomy-overlay.zip` 是**源码覆盖包**，不是独立 EXE。
它对应原项目基线提交 `147170f`。先取得该版本源码，再把压缩包中的 `pet/`、
`docs/`、`tests/` 和 `README.md` 按同名路径解压覆盖；修改前请备份你自己改过的文件。
本工作区另提供包含完整源码与原版动画的 Windows 测试包；首次使用 Conda 的步骤见
[`../WINDOWS-AI-TEST.md`](../WINDOWS-AI-TEST.md)。

## 打开方式

1. 使用 **Chat 版源码**运行，或从源码自己打包 Chat 版；原作者已发布的安装包并不包含本改动。
2. 在「桌宠设置 → AI 与对话 → 模型与连接」中配置好 OpenAI Chat Completions 兼容 API 的模型、地址和 Key，并测试连接。
3. 在同一页的「**AI 自主行为**」组里打开「让 AI 决定桌宠行为」。默认是**关闭**。
4. 先保持「允许自主识屏」**关闭**，让模型只根据桌宠状态和鼠标位置决策；需要真正观察屏幕再单独打开。
5. 调整「AI 决策间隔」：20–300 秒，默认 40 秒。关闭总开关立即停表并废弃迟到的决策结果。

从项目根目录、已激活好 Python 环境后：

```powershell
python -m pip install -r requirements.txt
python -m pet
```

配置凭据仍由原版 Chat 设置保管；**没有新增环境变量，也不需要另填一次 Key**。

## 模型选择了哪些行为？

| AI 意图 | 执行方式 |
|---|---|
| `idle` | 继续或切回原版待机动作 |
| `walk` | 用原版步态量化与边界限制走一段 |
| `approach_cursor` | 向当前鼠标水平位置走一段 |
| `retreat_cursor` | 远离当前鼠标走一段 |
| `look_at_cursor` | 朝向鼠标 |
| `turn` | 播放原版转身动画 |
| `play` + `animation` | 从当前角色实际存在的动作池选择一段动画，如跳舞、吃东西、打哈欠 |
| `say` / `say` 字段 | 通过原版气泡说一句话（不强制打开麦克风/TTS） |

模型必须输出受约束的 JSON 指令。未知动作、未知动画、控制系统的指令和不合格式的响应一律拒绝；
模型无法通过这个接口执行文件操作、系统命令、键盘和鼠标点击。

点击、拖拽、抛掷、飞行、碰撞和音乐唱歌等交互反馈仍**本地即时响应、优先于 AI**。
模型没返回动作或网络失败时会继续显示待机动画；总开关关闭后恢复原版随机游荡机制。

## 自动识屏与 API 费用

- **默认不截图**：未启用自主识屏时，每次请求只包含宠物/鼠标坐标、当前动画、时间、最近最多 8 次行为和可播放动画名单。
- **另行授权才截图**：启用后后台线程调用项目既有截图函数，全屏压缩 JPEG（最长边 768 px）只在内存中处理，发给配置的视觉 API，不写入磁盘。截图可能包含密码、聊天窗口等私人内容；请自行决定是否打开。
- **调用次数上限**：单次调用未完成时不会并发发起第二次；最短 20 秒，默认 40 秒。若 24 小时持续开着、请求足够快，默认频率最多约 **2160 次/天**，实际费用取决于服务商 token 价格及截图量。
- **超时**：每次网络请求最多等待 18 秒；失败不堵住 Qt 界面。模型需要支持 OpenAI 兼容的 `/chat/completions`，并能按提示返回 JSON。
- **屏幕图像的模型**：当前聊天模型不支持图片时，需在 AI 设置的视觉模型部分填入支持图片的模型和端点；否则视觉决策会失败，但聊天不会损坏。

## 边界与已知限制

- 这是**高层日常行为自主决策**，不是 Mochi 所有能力的逐行移植：本版未实现跨应用窗口栖息、主动读屏事件触发、持久长期记忆、文本 OCR、桌面自动操作等功能。
- 每次决策的上下文有限（最多最近 8 次动作）；角色复杂记忆和 AI 对话上下文没有合并。
- `walk` 和靠近/远离光标使用原版动画支持的**水平步态与安全边界**，并非任意精度的寻路或屏幕像素坐标控制。
- 无 Chat 变体没有此功能；不同插件或联动系统触发的专用行为可暂时覆盖 AI 待机。
- Windows 桌面实机视觉/动画连贯性需要在用户机器上验收；本工作区使用 Linux + Qt offscreen 测试，不能冒充 Windows 真桌面验证。

恢复原版行为：进入设置关闭「让 AI 决定桌宠行为」即可；旧版本读到新增配置字段会忽略它们。

## 2026-10-21：自主视觉与旧主动识屏的变更

原版独立「主动识屏」后台监视器已退役，不再单独截图和发起视觉回复。自主决策现在仅在 **允许自主识屏 + 非空进程白名单 + 当前前台程序在名单中** 同时满足时附带前台窗口区域截图，否则执行纯文字决策。具体规则和隐私边界见 [AI-SCREEN-WHITELIST.md](AI-SCREEN-WHITELIST.md)。
