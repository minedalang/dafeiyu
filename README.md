# 大肥鱼（DaFeiYu）· AI 自主桌面宠物

> 一只会自己安排日常活动、能与你聊天，也能通过 **OpenClaw** 帮你执行电脑任务的桌面小鲸鱼。

基于 [dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 二次开发，保留原有的小鲸鱼形象、WebM 动画与桌面交互，在此基础上加入 **大模型自主行为决策、生命状态、AI 对话、主动观察与 OpenClaw Agent 调用**。

**本项目是独立运行的桌宠程序，不需要 DSH 才能启动。** 当前 `/agent` 电脑任务功能使用 **OpenClaw Gateway**，与普通聊天、自主行为的模型调用分开配置。

> **项目状态：** 以 Windows 源码运行与持续开发为主。部分功能已通过代码测试，但不同模型服务、Windows 环境和 OpenClaw 版本的实际效果仍需自行验证；请勿将上游项目的 Release 视为本分支的安装包。

## 项目特色

| 功能 | 说明 |
| --- | --- |
| **AI 自主行为** | 大模型根据时间、桌宠状态、鼠标位置、最近经历等选择待机、走动、吃饭、休息、娱乐及现有动画，而不只是随机播放。 |
| **持续活动与多步动作** | 一次决策可以安排持续数分钟的活动；本地循环动画，必要时由模型更新活动阶段，无须每一帧都调用 API。 |
| **小鲸鱼生命系统** | 精力、饥饿、困意、心情随活动与时间改变；支持生活经历记录、睡眠恢复和有限的离线睡眠补算。 |
| **AI 对话与角色性格** | 支持多轮聊天、流式回复、角色提示词、聊天记录以及聊天触发的动作与表情。 |
| **自主搭话与点击回应** | 桌宠可以按可配置间隔决定是否主动说话；点击互动也可结合当前状态生成回应。 |
| **可选的屏幕感知** | 经单独授权后，可把受限的前台窗口或桌面画面提供给视觉模型，让行为和对话参考环境。 |
| **OpenClaw 电脑 Agent** | 通过 `/agent` 显式提交任务，由 OpenClaw 执行其获准的工具、浏览器或电脑操作。 |
| **聊天摘要共享** | `/agent` 可先用普通聊天模型压缩近期对话，再把摘要与当前任务发送给 OpenClaw；支持会话隔离与增量缓存。 |
| **保留原有桌宠体验** | 继续使用已有 WebM 动画、拖拽、点击、系统托盘、角色管理等基础能力，不要求 AI 实时生成动画。 |

## 三套 AI 能力如何分工

本项目将 **聊天、桌宠自主行为、电脑任务执行** 分成相互独立的调用链路：

```text
                         大肥鱼桌面程序
                                │
             ┌──────────────────┼───────────────────┐
             │                  │                   │
         日常 AI 对话       AI 自主行为           /agent 指令
             │                  │                   │
        聊天模型 API       行为决策模型 API      可选：聊天摘要 API
             │                  │                   │
         生成回复          输出受限动作计划              │
             │                  │                   ▼
         对话/气泡     桌宠本地动画与状态系统      OpenClaw Gateway
                                                    │
                                               指定的 Agent
                                                    │
                                             工具 / 电脑任务
```

### 1. AI 自主行为：决定小鲸鱼「做什么」

开启自主行为后，模型可以结合**本地时间、精力、饥饿、困意、心情、鼠标位置、最近活动与聊天上下文**安排日常活动。例如吃饭、散步、睡觉、学习、娱乐，或根据聊天内容做出情绪反应。

- AI 负责选择活动、动作和台词；本地程序负责移动、碰撞、动画播放与交互响应。
- 可以连续播放已有动作素材，睡觉、工作等长活动不需要逐帧请求模型。
- 长活动支持查看剩余时间；模型可在适当时机调整活动阶段。
- 可在「AI 决策状态面板」查看近期请求、选择的动作、活动计时和执行结果。
- **不会实时生成新的角色图像或动画**；只能选择当前素材包中存在的动作。
- 关闭自主行为后，仍可使用原有的桌宠随机行为。

### 2. 生命系统：让行为有连续性

小鲸鱼的生命状态在本地更新，而不是每次都让模型重新虚构：

- **精力**：工作与活动会消耗，休息和睡眠可以恢复。
- **饥饿**：随时间变化，完成吃饭活动后降低，同一餐避免重复结算。
- **困意与心情**：受睡眠、日夜时间和用户互动影响。
- **生活经历**：记录最近活动，供下一次 AI 规划参考。
- **离线睡眠**：根据本地夜间时段与关机前的午睡状态有限补算，避免重复恢复。

生命状态主要由本地逻辑维护；**模型参考状态做选择，而不是由固定阈值强制播放某个动画**。

更多规则见 [小鲸鱼生命机制说明](docs/WHALE-LIFE-MECHANICS.md)。

### 3. OpenClaw Agent：负责真正的电脑任务

普通聊天不会自动获得电脑操作权限。**只有明确使用 `/agent` 指令时，才会向 OpenClaw Gateway 提交电脑任务。**

```text
/agent 帮我检查 D:\PetDev 项目的 Python 依赖，并列出缺失项
```

调用方式：

1. 大肥鱼识别 `/agent` 指令。
2. 如果开启「附带压缩聊天摘要」，先由当前普通聊天 API 总结本会话近期文字记录。
3. 大肥鱼通过本机 OpenClaw Gateway 的兼容接口，把**摘要（如有）和当前任务**发给指定 Agent。
4. OpenClaw 使用自身已配置且获准的工具执行任务，并将回复返回大肥鱼聊天界面。

**重要区别：**

- 日常动作由大肥鱼的自主决策器负责，不依赖 OpenClaw。
- OpenClaw 负责电脑任务，不会因为大肥鱼能播放动作就自动获得鼠标、键盘或命令执行权限。
- 可在 OpenClaw 中创建独立的 `dafeiyu` Agent，与日常使用的 `main` Agent 分开管理人设、会话及工具权限。
- 大肥鱼设置里的「允许操作程序」**不会自动同步为 OpenClaw 的原生 Exec Approvals 白名单**；电脑任务仍受 OpenClaw 自己的审批和工具规则约束。

### 4. 智能摘要与聊天记忆

为避免将全部闲聊直接发送给 OpenClaw，`/agent` 支持可选的上下文压缩：

- 从**当前聊天会话**提取近期普通文字对话，不混入其他会话或旧 `/agent` 执行记录。
- 使用聊天窗口选定的模型及其独立 API 配置生成摘要。
- 摘要保存在本地缓存中；聊天未变化时直接复用，有新增消息时尝试增量更新。
- **发送给 OpenClaw 的是摘要和本次任务，不是原始聊天全文。**
- 如果摘要生成失败，会取消本次需要摘要的 Agent 调用，**不会自动改为发送原始对话**。
- 可以关闭摘要功能，仅发送当前 `/agent` 任务。

需要注意：生成摘要时，相关**原始聊天文本仍会发送给你选择的聊天 API 服务商**；OpenClaw 则接收生成的摘要。

## 快速开始

### 环境准备

- **主要使用环境**：Windows 10/11。
- **运行环境**：Python 3.11 推荐；可使用 Conda 隔离环境。
- **网络与 API**：普通 AI 对话、自主行为需要配置可用的模型 API；视觉功能需要支持图片输入的模型。
- **电脑 Agent（可选）**：需自行安装、启动并配置 OpenClaw Gateway。

### Windows 源码运行（推荐）

下载本仓库源码后，在项目根目录依次运行：

```text
1-Install-Windows.bat   # 安装 / 检查 Conda 环境及依赖
2-Run-Windows.bat       # 启动大肥鱼
```

如需在 Windows 本机自行构建可执行程序，可以使用：

```text
3-Build-Windows-EXE.bat
```

这些脚本属于源码运行 / 本机构建入口，**不表示仓库已经提供编译完成的 Windows 安装包**。详细步骤与故障排查见 [Windows 启动指南](WINDOWS-AI-TEST.md)。

也可在已正确安装依赖的 Python 环境中启动：

```powershell
python -m pip install -r requirements.txt
python -m pet
```

## 配置 AI 与 OpenClaw

### 普通聊天与自主行为

1. 打开大肥鱼的「AI 设置」。
2. 在「模型与连接」中添加 API Provider，填写相应的 **Base URL、API Key、协议、模型 ID**。
3. 在 AI 对话窗口单独选择 **聊天 API** 与模型；聊天模型和设置页当前选中的 Provider **不是同一个选择状态**。
4. 在「AI 自主行为」中选择决策模型并开启总开关；可调整决策间隔、持续活动和自主搭话间隔。
5. **自主识屏默认关闭**。确实需要视觉感知时，再单独授权。

### 电脑任务：连接 OpenClaw

1. 确保本机 OpenClaw Gateway 已运行，并启用了适用的 Chat Completions 接口。
2. 在「AI 设置 → 电脑 Agent（OpenClaw）」开启手动 Agent 任务。
3. 填写 Gateway 地址、Token 和 Agent 标识：

| 配置项 | 示例或说明 |
| --- | --- |
| Gateway 地址 | `http://127.0.0.1:18789`（本机默认示例） |
| Gateway Token | 使用你自己 OpenClaw 的授权 Token，切勿提交到仓库 |
| Agent 标识 | `openclaw/dafeiyu`（需提前创建该 Agent）；也可使用自己实际配置的入口 |
| 后端模型 / 思考级别 | 按需配置，不改变普通聊天 Provider |
| 附带压缩聊天摘要 | 可选，开启后在 `/agent` 前先生成摘要 |
| 最近普通聊天条数 | 默认 30 条，可在设置中调整 |

**OpenClaw 的系统提示词、工具白名单、命令审批、浏览器权限等，需要在 OpenClaw 中单独设置。** 本项目不会代替 OpenClaw 更改这些权限。

## 使用示例

**日常陪伴**

```text
陪我聊聊天，今天你想干什么？
中午啦，去吃点东西吧。
你今天是不是有点困了？
```

这些属于普通聊天；开启自主行为后，小鲸鱼还可以额外决定播放与情境匹配的已有动作。

**先聊天，再交给 Agent 执行**

```text
我最近在做一个 Python 项目，放在 D:\PetDev。请尽量后台检查，不要抢鼠标。

/agent 根据刚才讨论的内容，检查这个项目的目录结构和依赖
```

如果开启聊天摘要，OpenClaw 会收到近期对话的压缩背景和本次明确的任务指令，而不需要接收全部原文。是否能实际读取项目、运行命令，取决于 OpenClaw 的工作目录和工具授权。

## 隐私、费用与权限

- **API 费用**：普通聊天、行为决策、自主搭话、视觉分析、聊天摘要以及 OpenClaw 任务可能分别消耗模型 Token；本地动画循环与生命值定时更新不需要逐帧调用 API。
- **屏幕隐私**：自主识屏必须单独开启；一旦开启，授权范围内的截图可能被发送到你配置的视觉模型服务商。请避免在敏感信息窗口中开启此功能。
- **本地数据**：聊天会话、生命状态以及摘要缓存在本机保存。摘要缓存含明文摘要，不包含聊天原文；原始聊天仍按聊天会话的存储机制保存。
- **Agent 权限**：`/agent` 是显式任务入口，但不等于沙箱。高风险操作应通过 OpenClaw 的工具限制、命令审批和人工确认保护。
- **关闭方式**：可以分别关闭 AI 自主行为、主动识屏以及 OpenClaw Agent；这些功能不是必须同时开启。

## 开发说明与已知限制

项目使用 **Python + PySide6** 处理桌面窗口与动画，大模型输出高层动作决策，桌宠程序负责执行；OpenClaw 任务通过独立 Gateway 接口调用。

相关代码与说明：

| 位置 | 作用 |
| --- | --- |
| `pet/autonomy.py` | AI 自主行为相关逻辑 |
| `pet/desktop_agent.py` | `/agent` 的 OpenClaw Gateway 调用 |
| `pet/agent_context.py` | 聊天摘要、缓存与上下文隔离 |
| `pet/life_state.py` | 小鲸鱼生命状态 |
| [`docs/AI-AUTONOMY.md`](docs/AI-AUTONOMY.md) | AI 动作决策说明 |
| [`docs/WHALE-LIFE-MECHANICS.md`](docs/WHALE-LIFE-MECHANICS.md) | 生命状态与离线结算说明 |
| [`AGENT-CONTEXT-SUMMARY-V7.md`](AGENT-CONTEXT-SUMMARY-V7.md) | `/agent` 上下文共享与隐私边界 |

**当前需要注意：**

1. AI 自主行为不是每帧由模型实时控制，也不会生成不存在的动画素材。
2. 普通聊天、自主决策与 Agent 调用是独立请求，不能假定只进行一次 API 调用。
3. 使用 OpenClaw 的 `/agent` 功能需要 OpenClaw Gateway 正常运行且具备相应权限；没有安装 OpenClaw 时，桌宠聊天及自主活动仍可单独使用。
4. 上游保留的 DSH / 其他 Agent **状态联动**与这里的 **OpenClaw `/agent` 任务执行**是不同功能，不代表 `/agent` 已切换为 DSH 后端。
5. 本 README 描述的是独立分支的功能设计与源码入口，不构成所有 Windows 版本、模型、第三方服务均已完成端到端验证的保证。
